# OfferFlow 秋招雷达

一款面向 2027 届计算机求职者的本地投递管理 PWA。当前画像已按图神经网络、人工智能、机器学习工程、数据智能与全栈方向进行定制。

## 一键运行

Windows 双击 `启动 OfferFlow.cmd`。启动器会自动准备运行环境，等网站真正可访问后再弹出浏览器。首次运行通常需要几十秒。

也可以在项目目录执行：

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

## 已实现

- 总览、博士申请、投递管理、官网情报、截止日历、个人档案和数据备份独立分页
- 投递总览、状态跟踪、优先级与备注
- 添加、编辑、删除、搜索和筛选投递记录
- 投递记录按投递日期从新到旧自动排序
- 企业官网招聘情报、官网直达与来源核验日期
- 根据教育、科研、论文、奖项、技能和偏好实时计算岗位匹配度
- 根据研究方向实时计算博士目标匹配度
- 完整个人档案管理
- JSON 数据导入与导出备份
- 浏览器本地持久化，不上传个人信息
- 响应式桌面/手机界面与 PWA 安装支持

## GitHub Pages 发布

项目已包含 `.github/workflows/deploy-pages.yml`。推送到 GitHub 仓库的 `main` 分支后，在仓库的 Settings → Pages 中选择 GitHub Actions，发布完成后即可获得公开链接：

```text
https://你的用户名.github.io/仓库名/
```

页面使用 `#/overview`、`#/applications` 等 Hash 路由，刷新独立页面不会出现 404。

## 数据说明

首版官网信息核验日期为 2026-08-30。企业没有公开固定截止日时，页面明确标注“招满即止”“官网在招”或“以职位页为准”，不会虚构日期。投递前请点击“进入官网”进行最终确认。

当前官方来源包括腾讯音乐娱乐、百度、字节跳动 Seed、华为、美团与字节跳动校园招聘官网。

## 隐私

网站只把投递记录保存在当前浏览器的 `localStorage`。简历中的手机号、邮箱、照片等没有写入网站。清理浏览器数据前，建议先点“导出备份”。
